# Code-Bud: Antigravity IDE & Autonomous Coding Agent

Code-Bud is an autonomous AI-powered code workspace and IDE built for pair-programming and real-time software generation. It combines a FastAPI streaming backend, an agent layer powered by Pydantic AI with NVIDIA NIM / Groq / OpenAI model routing, and a clean web-based IDE frontend.

---

## 🏛️ Project Architecture

Code-Bud is organized into an explicit 5-part architecture:

```
code-bud/
├── packages/              # 1. Package definitions & configuration
│   ├── .env               # Local environment secrets (ignored by git)
│   ├── .env.example       # Sample environment template
│   ├── pyproject.toml     # Root workspace configuration
│   ├── uv.lock            # Deterministic dependency lockfile
│   └── shared/            # Shared Pydantic models, schemas & configs
│       └── src/shared/
│           ├── config.py  # App settings loader (.env / environment)
│           └── models.py  # FileItem, ChatRequest, CommandResponse, etc.
│
├── frontend/              # 2. Web IDE Client
│   ├── index.html         # Chrome UI layout with curved SaaS aesthetics
│   ├── css/               # Modular stylesheet rules
│   ├── src/               # TypeScript frontend modules
│   │   ├── api.ts         # REST & SSE streaming client
│   │   ├── chat.ts        # Agent interaction panel & streaming markdown
│   │   ├── editor.ts      # Multi-tab code editor, line numbers & minimap
│   │   ├── explorer.ts    # File tree explorer with create/delete actions
│   │   ├── terminal.ts    # Output viewer & run command dispatcher
│   │   └── main.ts        # UI orchestrator & keyboard shortcuts
│   └── dist/              # Bundled distribution (main.js)
│
├── backend/               # 3. FastAPI REST & SSE Backend
│   ├── main.py            # FastAPI application factory & static mounts
│   ├── dependencies.py    # Dependency injection & workspace resolution
│   └── routes/
│       ├── chat.py        # SSE /chat/stream & /chat endpoints
│       ├── files.py       # File CRUD, run script & delete endpoints
│       ├── terminal.py    # Shell command execution endpoint
│       └── health.py      # Healthcheck probes
│
├── agents/                # 4. Autonomous Agent Layer
│   ├── README.md          # Dedicated Agent & Tools Documentation
│   ├── core.py            # Pydantic AI Agent factory & LLM provider router
│   ├── context.py         # AgentDeps dependency contract & state
│   ├── prompts.py         # Agent system prompt & tool call instructions
│   └── functions/         # Modular tool functions
│       ├── write.py       # Creates or overwrites files
│       ├── read.py        # Inspects files by line ranges
│       ├── edit.py        # Surgical search-and-replace editing
│       ├── ls.py          # Directory listing with depth filtering
│       ├── grep.py        # Regex search across project files
│       ├── find.py        # Glob pattern file search
│       └── bash.py        # Workspace command runner
│
└── user_files/            # 5. User & AI Workspace
    └── (files added by user or autonomously generated by the AI agent)
```

## ✨ Features

- **Autonomous Agent Pairing**: Prompt the agent to create scripts, refactor algorithms, debug errors, or add features.
- **Dedicated `user_files/` Workspace**: All code generated by the agent or uploaded by the user is isolated in `user_files/` with path traversal protections.
- **Live Output Runner (`▶ Run`)**: Execute Python, JavaScript, and shell scripts with 1-click in the browser. Captures stdout, stderr, execution duration, and exit codes.
- **External Terminal Launcher (`↗ Run in Terminal`)**: Launches native interactive console windows for running interactive CLI programs (e.g. `cmd.exe /k python ...`).
- **File Explorer & Editor**: Full file tree with file creation, inline renaming, live tab management, syntax highlighting, line numbers, minimap, and file deletion.
- **Real-time SSE Streaming**: High-throughput delta token streaming with tool invocation tracking and automatic file refresh upon completion.
- **Multi-Provider LLM Routing**: Native support for:
  - NVIDIA NIM (`z-ai/glm-5.3-flash`, `meta/llama-3.3-70b-instruct`)
  - Groq (`llama-3.3-70b-versatile`)
  - OpenAI (`gpt-4o`, `gpt-4o-mini`)

## 🚀 Quickstart

### Prerequisites
- **Python**: `>= 3.12`
- **uv**: Fast Python package manager ([Astral uv](https://docs.astral.sh/uv/))
- **Node.js**: (Optional, only needed if rebuilding frontend assets)

### 1. Installation
Navigate to the project directory and install dependencies using `uv`:

```bash
cd code-bud
uv sync
uv pip install -e packages/shared
```

### 2. Environment Configuration
Copy the sample environment file:

```bash
cp .env.example .env
```

Edit `.env` and configure your API key:

```ini
NVIDIA_API_KEY=nvapi-your-key-here
AGENT_MODEL=nvidia:z-ai/glm-5.3-flash
HOST=127.0.0.1
PORT=8000
```

### 3. Launch the IDE
Start the server with `run.py`:

```bash
uv run python run.py
```

Open your browser at:
```
http://127.0.0.1:8000
```

## 🛠️ Rebuilding Frontend (Optional)

If modifying TypeScript files under `frontend/src/`:

```bash
cd frontend
npm install
npm run build
# Or directly via esbuild:
npx esbuild src/main.ts --bundle --outfile=dist/main.js
```

## 📡 API Reference

| Endpoint | Method | Description |
|---|---|---|
| `GET /api/health` | GET | Healthcheck status and uptime |
| `GET /api/files/info` | GET | Workspace root path, name, git branch, and python version |
| `GET /api/files/tree` | GET | Recursive file tree of `user_files/` |
| `GET /api/files/content?path=...` | GET | Retrieve text content of a specific file |
| `POST /api/files/save` | POST | Save or update file content |
| `POST /api/files/create` | POST | Create a new file or directory |
| `DELETE /api/files/delete?path=...` | DELETE | Delete a file or directory |
| `POST /api/files/run` | POST | Execute a script within `user_files/` and return output |
| `POST /api/files/run-terminal` | POST | Open an external terminal window running the file |
| `POST /api/chat/stream` | POST | Server-Sent Events (SSE) streaming chat endpoint |
| `GET /api/chat/models` | GET | List available models |
